SQL Projects & Advanced Query Portfolio

Overview
This repository showcases my SQL skills through a collection of complex, business-oriented data challenges and analytical queries. The projects focus on transforming raw data into meaningful business insights, building multi-layered queries, performing financial and operational audits, and solving analytical problems using SQL.

Each project started with a business scenario and a set of technical requirements. I developed the SQL queries to address those requirements, applying different SQL concepts and analytical techniques.



Technical Skills Demonstrated
Data Cleaning & Standardization: TRIM(), UPPER(), LOWER(), SUBSTRING(), REPLACE(), COALESCE()
Data Aggregation: SUM(), AVG(), COUNT(), MAX(), ROUND()
Conditional Logic: CASE WHEN, conditional aggregation
Data Filtering: WHERE, HAVING, BETWEEN, IN, LIKE, NOT LIKE
Joins & Relationships: INNER JOIN, multi-table joins
Advanced Query Architecture: Common Table Expressions (CTEs), multi-step query pipelines
Set Operations: UNION ALL
Window Functions: ROW_NUMBER(), DENSE_RANK(), LAG(), running totals, moving averages
Date & Time Analysis: Date parsing, date extraction, chronological analysis, transaction velocity
Financial Analysis: Payroll calculations, bonus compensation, currency conversion, signed cash flows, cumulative balances
